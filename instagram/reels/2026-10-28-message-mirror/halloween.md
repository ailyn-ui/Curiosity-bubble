# The Message Mirror – Halloween version

Same offer and caption/DMs as [README.md](README.md); shorter script in Ailyn's own words, with a haunted-mirror concept. Post by Oct 30–31.

## Script (~11s)

```
What if it wasn't you?
Maybe there's a gap
between what you say and what is heard.
So I made The Message Mirror.
A quick tool to get clear.
Comment "mirror."
```

Optional loop ending: `Comment "mirror." It wasn't you.`
